# E-Commerce Database Testing

## Project Overview
This project focuses on database validation for an e-commerce system using SQL Server and SQL queries. It covers relational data structures, data integrity, foreign-key relationships, and validation of customer, product, and order information.

Playwright and TypeScript are also used for automated testing of relevant e-commerce workflows where applicable.

## Project Objectives
- Understand relational database structures. 
- Validate data integrity using SQL queries.
- Verify relationships between database tables.
- Check product prices and customer-order associations.
- Practice database validation alongside test automation.

## Tools & Technologies
- **SQL Server:** Database management
- **SQL:** Data retrieval and validation
- **Playwright:** UI workflow automation, where applicable
- **TypeScript:** Automation scripting
- **Git & GitHub:** Version control

## Database Structure
The database includes the following tables:

- **Customers:** Customer information
- **Products:** Product information and prices
- **Orders:** Order records
- **Order Items:** Products associated with individual orders
- **Payments:** Payment-related records

## Testing Scope

### 1. Data Integrity
- Validate data using SQL queries.
- Check relationships between related records.
- Verify foreign-key relationships.

### 2. Customer and Order Validation
- Validate customer-order associations.
- Check the relationships between customers and their orders.

### 3. Product Validation
- Verify product prices using SQL queries.
- Validate relationships between products and order records.

### 4. Workflow Automation
- Use Playwright and TypeScript to automate relevant e-commerce workflows where implemented.

## Key Learning Outcomes
- Writing SQL queries for data validation.
- Understanding relational database relationships.
- Checking data integrity and foreign-key constraints.
- Validating customer, product, and order information.
- Understanding the relationship between UI testing and database testing.

## Conclusion
This project demonstrates my understanding of SQL-based data validation, relational database testing, data integrity checks, and the role of automation in e-commerce quality assurance.
